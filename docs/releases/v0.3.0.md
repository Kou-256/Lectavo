# Lectavo 0.3.0

動画に加え、音声ファイルからも文字起こしとノートを作成できるようになりました。

## 新機能

- MP3・M4A・WAVからTXT・SRT・Markdownを出力。音声のみの場合はスライド解析を行いません。
- 動画プレビュー上で、抽出するスライド範囲とページ番号領域を指定。ドラッグ・数値入力・プレビュー時刻変更に対応します。
- 起動時または設定画面で更新を確認。ダウンロード前とインストーラー起動前に、それぞれユーザーの確認を取ります。
- 更新ファイルのSHA-256・サイズ・配布元を検証し、不完全なダウンロードは使用しません。ダウンロードはキャンセル可能です。
- 起動時確認は設定から無効にできます。ネットワークが使えなくても動画・音声のローカル処理は可能です。
- ホーム・履歴・設定・ヘルプにSVGアイコンを追加しました。
- 画像解析ライブラリとGPU診断を遅延読み込みし、起動を軽量化しました。繰り返し起動した場合は既存ウィンドウを表示します。
- 音声の末尾の無音も含むファイル長を使い、統合SRTの時刻を連結します。同名の入力ファイルを個別出力するときも名前を区別します。

## アップグレード

0.2.xをご利用の場合は、一度だけ最新のLectavo-Setup.exeで上書きインストールしてください。アプリ内の更新確認機能は0.3.0以降で利用できます。処理中のインストールは保留し、処理が終わった後で確認します。

手動で指定した検出範囲は選択した全動画に適用されます。動画ごとに画面構成が違う場合は、別々に範囲を設定して処理してください。

配布物は未署名です。SHA256SUMS.txtに各ファイルのハッシュを掲載しています。Whisperモデルはインストーラーに含まれず、初回に取得します。

## English

- Audio transcription for MP3, M4A, and WAV with TXT, SRT, and Markdown output.
- Visual slide and page-number region selection with video seeking and numeric controls.
- Background update checks, explicit consent before download and installation, SHA-256 verification, and cancellation.
- Faster startup, single-instance window activation, and SVG navigation icons.
- Upgrade manually from 0.2.x once to enable future in-app update checks. This release is unsigned.
