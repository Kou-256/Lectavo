# Lectavo 0.4.2

## 新機能

- **時間ごとの検出範囲**: 動画の途中で画面の配置が変わる場合に対応しました。範囲指定画面でスライダーを配置が変わる時刻に動かし、「この時刻から範囲を変える」を押して緑の枠を指定します。区間は「時間ごとの範囲」に一覧表示され、「区切りを削除」「共通の範囲に戻す」で取り消せます。設定は動画ごとに保存され、設定していない動画は全ファイル共通の範囲を使います。範囲が切り替わった時点のスライドは、既存のスライドと重複しない限り保存されます。
- **ページ番号なし**: 設定画面の「スライドにページ番号がない」、または範囲指定画面の「ページ番号なし」をオンにすると、ページ番号の変化では切り替わりを判定しません。

## 改善

- 範囲指定画面を最大化・最小化でき、ウィンドウに合わせてプレビューが大きくなります。「自動検出に戻す」は選択中の区間だけに適用されます。
- 「まとめて出力」では、処理ごとに出力名のフォルダ（例: `講義サンプル_2026-11-17_10-00-00`）を作り、PDF・TXT・SRT・MD・`slides` フォルダをその中に保存します。「出力フォルダを開く」はこのフォルダを開きます。
- スライドの確認・修正で場面を追加するとき、その時刻に使われていた範囲で切り抜きます。
- インストーラーの右上の画像を表示しないようにしました。

`Lectavo-Setup.exe` は旧版のアプリ内更新用の互換ファイルで、`Lectavo-setup-0.4.2-x64.exe` と同じ内容です。どちらか一方だけをインストールしてください。配布物は未署名です。

## English

Adds per-video crop timelines for layouts that change mid-video, a "no page numbers" option, a maximizable crop dialog, and one output folder per combined run containing every file. The installer no longer shows an image in the top-right corner.
