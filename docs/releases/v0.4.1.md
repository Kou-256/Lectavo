# Lectavo 0.4.1

デザインを整えた更新です。処理内容は0.4.0から変わりません。

## 改善

- インストーラーの画像を、Inno Setup既定の箱とディスクの絵からLectavoのデザインに変更しました。高解像度の画面でもくっきり表示されます。
- サイドバーにアプリアイコンを表示し、選択中のメニューはアイコンも強調表示します。
- 処理画面のファイル一覧を、種類アイコン（動画・音声）、省略表示のファイル名、色分けした状態（完了・処理中・注意・エラー・待機中）で、同じ高さにそろえました。
- 区切り線を細く控えめにしました。
- 設定画面の項目名の幅と位置をそろえ、「スライド検出の詳細」などの展開ボタンを矢印アイコンにしました。「画面で検出範囲を指定」はアイコン付きの小さなボタンになりました。

`Lectavo-Setup.exe` は旧版のアプリ内更新用の互換ファイルで、`Lectavo-setup-0.4.1-x64.exe` と同じ内容です。どちらか一方だけをインストールしてください。配布物は未署名です。

## English

A design update; processing is unchanged from 0.4.0. The installer shows Lectavo artwork instead of the default box-and-disc images. The sidebar shows the app icon and highlights the active item's icon. Input files are fixed-height rows with a type icon, an elided name, and a colored status. Separators are thinner, settings labels are aligned, and expandable sections use chevron icons.
