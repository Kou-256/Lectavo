# Lectavo 0.5.1

## 改善

- **PDF翻訳の精度**: 論文の表紙のように、ページ全体が1枚の図として埋め込まれたページも翻訳するようにしました。
- **参考文献はそのまま**: 参考文献リストは原文のまま残し、訳文で行がつながってレイアウトが崩れないようにしました。
- **訳のずれを自動で修正**: 訳文が隣の段落のものになっていた場合は、その段落だけ訳し直します。以前の翻訳で保存された、ずれた訳も使わずに訳し直します。
- 段落の途中で切り出された文字（例: 「Furthermore,」）が、段落の上に重なって表示される問題を修正しました。
- 人名・日付・IPアドレスは原文のまま残すよう、翻訳エンジンに指示するようにしました。
- **内蔵ローカルLLMの標準モデルをGemma 4 12B（7.2GB）に変更しました**。より正確で自然な訳文になります。ダウンロードするまでは、ダウンロード済みのモデルで翻訳を続けられます。ダウンロード後は自動でGemma 4 12Bに切り替わります（設定画面で別のモデルを選んでいる場合はそのままです）。GPU（VRAM 8GB以上）か32GBメモリを推奨します。
- **比較画面**: ページの一番下（上）でさらにスクロールすると、次（前）のページへ移動します。ページ番号欄の上下ボタンは、左右ボタンと役割が同じため削除しました。
- **インストーラー**: 「デスクトップにアイコンを作成」「スタートメニューに登録」を、更新時も毎回オンの状態で表示するようにしました。

`Lectavo-Setup.exe` は旧版のアプリ内更新用の互換ファイルで、`Lectavo-setup-0.5.1-x64.exe` と同じ内容です。どちらか一方だけをインストールしてください。配布物は自己署名です（発行元「Lectavo / Kou Hashizume」）。信頼された認証局の証明書ではないため、Windowsで「発行元を確認できません」と表示される場合があります。

## English

PDF translation now handles cover pages embedded as a single graphic, keeps reference lists in the original language, re-translates paragraphs whose answer was shifted to a neighbouring paragraph, and keeps names and dates as written. Gemma 4 12B is the new default built-in model; a model already downloaded is used until it is installed. In the comparison view, scrolling past the end of a page turns the page, and the page number box no longer has up/down arrows. The installer's desktop and Start Menu shortcut boxes are checked on every update.
