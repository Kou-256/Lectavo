# Lectavo 0.4.4

## 新機能

- **動画と同じフォルダに保存**（初期設定でオン）: 結果を入力した動画・音声のフォルダに保存します。「動画ごとに出力」では各動画のフォルダの中に結果フォルダを、「まとめて出力」では最初の動画のフォルダに処理ごとのフォルダを作ります。処理画面では保存先の入力欄の代わりに「保存先: …」と表示します。オフにすると従来どおり保存先を選べます。設定画面と処理画面の切り替えは連動します。

## 改善

- 設定画面と処理画面の項目を、項目名と入力欄の2列にそろえました。「画面で検出範囲を指定」「ページ番号」「スライド検出の詳細」「開発者向け」も入力欄の列に並びます。
- 「スライド検出の詳細」「開発者向け」を開閉したときに画面がちらつく問題を修正し、滑らかに開閉するようにしました。
- 各セクションの見出しと区切り線を統一しました。
- ファイル一覧の状態表示の丸を図形にし、ホームの手順カードの見出しに番号を入れました。

`Lectavo-Setup.exe` は旧版のアプリ内更新用の互換ファイルで、`Lectavo-setup-0.4.4-x64.exe` と同じ内容です。どちらか一方だけをインストールしてください。配布物は未署名です。

## English

Results are now saved next to the input files by default (per-video output beside each video, combined output beside the first video); turn it off to choose a folder as before. Settings and the Process screen align every field in one label and field column, and the detail sections open and close smoothly without flicker.
