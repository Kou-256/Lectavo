# Lectavo 0.4.3

## 改善

- **範囲指定のコマ送り**: 「画面で検出範囲を指定」の画面に「−1秒」「−1コマ」「+1コマ」「+1秒」ボタンを追加しました。キーボードでは ←→ で1コマ、Shift+←→ で1秒移動できます。
- 時刻を 0.01 秒単位とコマ番号で表示します。プレビューは指定した時刻のフレームを正確に読み込むため、画面の配置が切り替わる瞬間に合わせて「この時刻から範囲を変える」を押せます。
- 「時間ごとの範囲」の一覧も 0.01 秒単位で表示し、区間を選ぶとその開始フレームへ移動します。

`Lectavo-Setup.exe` は旧版のアプリ内更新用の互換ファイルで、`Lectavo-setup-0.4.3-x64.exe` と同じ内容です。どちらか一方だけをインストールしてください。配布物は未署名です。

## English

The crop dialog gains −1s, −1 frame, +1 frame, and +1s buttons, with ←/→ for one frame and Shift+←/→ for one second. Times are shown to a hundredth of a second with the frame number, and the preview loads the exact frame, so change points can be placed exactly where the layout switches.
