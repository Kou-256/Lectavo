# Lectavo 0.3.1

## 改善と修正

- 4Kディスプレイで公式サイトのテキストが1文字ずつ改行される不具合を修正しました。
- ホーム画面と処理画面を分離しました。処理画面の左側で入力ファイルをタブ形式で管理できます。
- ファイル選択とファイルタブでCtrl／Shiftの複数選択に対応。左のファイル一覧は幅をドラッグ調整でき、選択ファイルを一括削除できます。設定は全ファイルに共通です。
- 無音、発話未検出、モデル読み込み失敗を別の状態として表示します。無音ではモデルを読み込まず、理由をTXTとノートに記録します。
- model.binが開けない場合は通常ファイルの修復コピーで再試行し、不完全なキャッシュは必要ファイルを再取得します。既存キャッシュは削除しません。
- 全入力が失敗した場合に空の統合ノートを生成する問題を修正しました。
- インストーラー名にバージョンとアーキテクチャを追加しました: `Lectavo-setup-0.3.1-x64.exe`。

0.3.0のアプリ内更新に対応するため、同一内容の `Lectavo-Setup.exe` も提供します。どちらか一方だけをインストールしてください。配布物は未署名です。

## English

Fixed 4K website layout, added separate Home/Process screens and a Ctrl/Shift multi-select file rail, distinguished silent audio from missing speech and model errors, repaired unreadable model caches, and added versioned x64 installer names.
