# Lectavo 0.5.5

## 改善

- **動画・音声のプレビュー**: 処理画面で、一覧から選んだ動画や音声を、入力ファイルの下で再生して確認できます。再生・一時停止、シークバー、再生時間、消音があります。処理を始めたときや別の画面に移ったときは自動で一時停止します。
- **PDF翻訳: グラフの目盛り**: 目盛りの数字（例:「10 15」）が軸の名前と一緒に読み取られ、まとめて翻訳される問題を修正しました。数字だけの行は元のまま残します。
- **PDF翻訳: はみ出した文字**: フォントが埋め込まれていないPDFで、文字が寸法より長く描かれていると、訳文の横に原文の文字（例:「t.」）が残ることがありました。実際に描かれた文字の端まで覆うようにしました。

`Lectavo-Setup.exe` は旧版のアプリ内更新用の互換ファイルで、`Lectavo-setup-0.5.5-x64.exe` と同じ内容です。どちらか一方だけをインストールしてください。配布物は自己署名です（発行元「Lectavo / Kou Hashizume」）。信頼された認証局の証明書ではないため、Windowsで「発行元を確認できません」と表示される場合があります。

## English

The processing page now plays the selected video or audio file so it can be checked before processing (play/pause, seek, mute). PDF translation no longer translates graph tick numbers together with the axis title, and no longer leaves stray original letters beside translations when a PDF draws text wider than its font metrics.
