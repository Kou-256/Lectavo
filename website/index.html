WHAT YOU CAN DO

動画と録音を、
読み返せる資料に。

下の画像はすべて、サンプル動画を実際に処理した結果です。

長い講義から、スライドだけを取り出す

スライドが切り替わった場面だけを画像にし、1ページ1枚のPDFにします。マウスやポインターの小さな動きは無視します。

分割された動画を、1つの資料にまとめる

名前順（01、02…10）に処理し、動画をまたいで重複するスライドは1回だけ載せます。

動画の音声や録音を、文字で読む

faster-whisperで時刻付きテキストとSRT字幕を作ります。MP3・M4A・WAVだけでも使えます。

スライドと、そのときの説明を並べる

スライドの表示時間と発話を照合し、Markdownの講義ノートにまとめます。

登壇者や操作パネルを、抽出範囲から外す

プレビュー上でスライドの範囲をドラッグで指定。1コマ・1秒単位で送りながら、配置が変わる時刻から範囲を切り替えられます。

まとめて保存も、ファイル別の保存も

結果は動画と同じフォルダに保存（変更も可能）。1フォルダにまとめるか動画ごとに分けるかを選び、ファイル名には共通名や日時を付けられます。

読み込めるファイル

動画
MP4 / MOV / MKV / AVI / WEBM / M4V
音声
MP3 / M4A / WAV

手元のファイルを処理します。URLから動画を取得する機能はありません。

BEFORE YOU START

使う前に、知っておきたいこと。

途中でアプリを閉じたり、エラーになったりしたら？

完了した部分は自動で保存されます。ホームの「続きから再開」、またはエラー画面の「続きから再実行」で残りだけを処理します。

GPUやAPIキーは必要ですか？

どちらも不要です。CPUだけで動きます。NVIDIA GPUがあれば文字起こしが速くなります。

ファイルは外部へ送信されますか？

送信しません。処理はすべてPC上で行います。ネット接続は、初回のモデル取得と更新確認だけに使います。

結果は必ず正確になりますか？

完全ではありません。よく似たページは取り逃すことがあるので、完了後の「スライドを確認・修正」で補えます。文字起こしも、重要な箇所は元の録音で確認してください。

無音とエラーは見分けられますか？

はい。「無音」「発話未検出」「モデルのエラー」を区別して表示します。

自動要約や文字検索もできますか？

現在は対応していません。PDFのページは画像です。発話の検索にはTXTやMarkdownを使ってください。
