Lectavo

講義動画を、
PDFと文字起こしへ。

スライドの切り替わりを見つけ、重複を除き、faster-whisperで発話を整理。 複数の動画も一つの講義資料にまとめます。

Windows版をダウンロード ↓ GitHubで見る

Version 0.2.1 ・ 無料 ・ Python不要

Slide detection 局所変化を除外
Deduplication 動画をまたいで照合
Whisper CUDA NVIDIA GPU対応

01 / WORKFLOW

動画を選ぶ。
資料ができる。

カーソルやレーザーポインターの移動は無視し、意味のあるスライド変化だけを検出します。 PDF、タイムスタンプ付き文字起こし、スライド別Markdownまで一つの流れで生成します。

01 動画 MP4 / MOV / MKV
02 スライド検出 SSIM + 差分解析
03 重複除去 pHash + SSIM
04 文字起こし faster-whisper
05 資料完成 PDF / TXT / SRT / MD

処理中動画を読み込んでいます

02 / GPU TRANSCRIPTION

faster-whisperを、
NVIDIA GPUで。

CUDA 12向けcuBLASランタイムをアプリに同梱。対応するNVIDIA GPUとcuDNN 9環境では、 faster-whisperの文字起こしをGPUで実行できます。

Runtime
CUDA 12 / cuBLAS
Engine
faster-whisper 1.2.1
Fallback
CPU int8へ自動切替

GPUや必要DLLを利用できない場合も停止せず、「CUDAが使えないためCPUで続行しました」と通知します。

03 / OUTPUTS

戻ったページも、
複数動画も、きれいに一つへ。

PDF

重複のないスライド

前ページへ戻った場面や、複数動画間で再登場したスライドを除外します。

TXT

読める文字起こし

自然な言語検出とタイムスタンプ付きTXT・SRTに対応します。

MD

スライド別の講義ノート

画像と、そのスライドが表示されていた間の発話をMarkdownへまとめます。
