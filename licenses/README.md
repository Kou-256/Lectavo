# Third-party license files

This directory is included in packaged Lectavo distributions.

- `DEPENDENCY_LICENSES.txt`: generated package/version/license inventory.
- `LGPL-3.0.txt` and `GPL-3.0.txt`: GNU license texts used by Qt/FFmpeg options.
- `PyAV-BSD-3-Clause.txt`: PyAV license.
- `OpenCV-LICENSE.txt` and `OpenCV-THIRD-PARTY.txt`: OpenCV and bundled
  third-party notices, including its video I/O FFmpeg component.
- `ReportLab-BSD.txt`: ReportLab license.
- `NVIDIA-CUDA-Toolkit-EULA.txt`: NVIDIA runtime terms.
- `PYAV-FFMPEG-BUILD-INFO.txt`: versions and configure options reported by PyAV.

`THIRD_PARTY_NOTICES.txt` in the application root provides the human-readable
summary. Review all licenses again whenever pinned dependencies change.
